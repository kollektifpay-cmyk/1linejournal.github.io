# 1 Line Journal - Landing Page & Privacy Policy

This repository contains the official website and privacy policy for the 1 Line Journal mobile app.

## 🌐 Live Site
https://1linejournal.github.io

## 📄 Contents

- **index.html** - Landing page
- **privacy-policy.html** - Privacy Policy (required for Google Play Store)

## 🚀 Setup

1. Upload these files to your GitHub repository
2. Go to GitHub Settings → Pages → Source: select `main` branch
3. Your site will be live at https://1linejournal.github.io in a few minutes

## 📱 About the App

1 Line Journal makes journaling simple and sustainable. Write just one sentence a day to capture your life.

### Features
- 🔥 Streak system to build habits
- 📊 Statistics & mood analytics
- 🗓️ On This Day memories
- 🔒 Secure & encrypted
- 🌍 6 languages supported
